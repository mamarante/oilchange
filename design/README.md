# Design previews

Static HTML previews of the app's design tokens and components, synced to the
"Oil Change" project in [Claude Design](https://claude.ai/design). Each file
mirrors real values from `src/constants/theme.ts` and the corresponding
component under `src/components/` — colors, spacing, type, buttons, badges,
cards, and form fields.

These are reference/preview artifacts for visual iteration, not app code —
nothing here is imported by the Expo app itself. When a design changes here,
update the matching RN component/token by hand.
